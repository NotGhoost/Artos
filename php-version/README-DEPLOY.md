# Artos (artos.by) — как выложить на хостинг

Настоящий сайт на PHP + MySQL. JS и CSS лежат отдельными файлами — как вы и спрашивали.

## Структура
```
index.php            каталог (главная), фильтры работают и без JS, и через JS
painting.php?id=     страница картины + форма заявки
artist.php?id=       биография художника + его картины
api/paintings.php    JSON для живых фильтров (его дёргает assets/js/app.js)
assets/css/style.css все стили
assets/js/app.js     весь клиентский JavaScript
assets/img/          стартовые фото картин и художников
uploads/             сюда админка складывает загруженные фото (нужны права на запись)
admin/               админка: картины, художники, заказы (только роль admin)
inc/                 config.php, подключение к БД, шапка/подвал (закрыто через .htaccess)
database/schema.sql  структура и демо-данные для MySQL
```

## Запуск на виртуальном хостинге (по шагам)
1. **База данных.** В панели хостинга создайте базу MySQL и пользователя, запишите: имя базы, пользователя, пароль.
2. **Импорт.** Откройте phpMyAdmin → ваша база → «Импорт» → загрузите `database/schema.sql`. Появятся таблицы, 3 художника, 3 картины-примеры и админ.
3. **Конфиг.** Скопируйте `inc/config.example.php` в `inc/config.php` и впишите данные базы из п.1 (`db_driver` оставьте `mysql`).
4. **Файлы.** Загрузите всё содержимое папки `artos/` в `public_html` (или `www/artos.by`) домена — так, чтобы `index.php` оказался в корне сайта. Папке `uploads/` нужны права на запись (обычно 755 хватает, если PHP работает от вашего пользователя; иначе 775).
5. **Домен.** У регистратора artos.by должны быть NS/DNS хостинга (обычно A-запись на IP сервера + привязка домена в панели хостинга). HTTPS: включите бесплатный Let's Encrypt в панели и «принудительный HTTPS».
6. **Первый вход.** `https://artos.by/login.php` → `admin@example.ru` / `dub2024`. **Сразу** зарегистрируйте свой админ-аккаунт… точнее: создайте в phpMyAdmin нового пользователя с role=admin и своим паролем-хэшем, либо попросите меня сделать страницу смены пароля — и удалите демо-админа.
7. **Под себя.** В `inc/header.php` и `inc/footer.php` поменяйте адрес, телефон (+375 …) и почту `hello@example.by` на настоящие.

## Локальная проверка (без хостинга)
В `inc/config.php` стоит `db_driver=sqlite` — таблицы и демо-данные создаются сами при первом открытии. Запуск: `php -S localhost:8000 -t artos`. На хостинг этот config.php не заливайте — там нужен mysql из примера.

## Заказы
Форма на странице картины создаёт заявку (таблица `orders`), картина автоматически становится «Забронирована». Онлайн-оплаты пока нет: менеджер перезванивает и обсуждает оплату/доставку — так вы и выбрали. Статусы меняются в `admin/orders.php`, при отмене бронь снимается.
